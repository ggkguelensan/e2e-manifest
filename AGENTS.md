# E2E Manifest

Начни с [режима установки](docs/installation.md). Для изменения базы задай `E2E_MANIFEST_DEV=1`; для применения закрепи ревизию базы и выбери стековые модули для target. Режим независим от имени ветки. Не переключай ветку автоматически.

Использование: прочитай [локальные границы](docs/local-workflow.md), применимые проектные требования, затем выбери нормы по [маршрутизации](README.md#выбери-детали). Не загружай отсутствующие стековые модули по предположению.

Сопровождение: сначала [SSOT-аудит](docs/maintenance.md), затем затронутые нормы и потребители. Выполни `npm run check`, `npm test`, `git diff --check`. Исходники инструментов — TypeScript. Нормативная база не хранит данные продукта.

`workdir/` — игнорируемая долговременная локальная адаптация. Не удаляй её при очистке или обновлении. Результаты аудита и тестовые probes — в игнорируемом `e2e/tmp/`. Не публикуй работу без поручения.
