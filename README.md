# E2E Manifest

Правила и инструменты локальной проверки настоящего приложения: сценарии, тестовая инфраструктура, покрытие, evidence и отчёты. Манифест адаптируется к выбранному target; результаты каждого worktree независимы.

Вход агента и маршрутизация задач — [AGENTS.md](AGENTS.md). Для установки базы, выбора модулей и локальных hooks прочитай [installation](docs/installation.md). Development/consumer режим задаётся явно и не определяется именем ветки.

Общая база находится вне продукта. Её workdir/ хранит долговременную адаптацию; продуктовый e2e/ — тестовую инфраструктуру и краткие инструкции; target/e2e/tmp/ — рабочие CSV/JSON, evidence и HTML. Подключённый Project Manifest выбирает repository/target/worktree; Design Manifest владеет дизайн-источниками и сравнением. Самостоятельное использование E2E сохраняется.

Архитектура и границы доказательств определены в [норме слоёв](docs/architecture.md), [контрактах](docs/contracts.md) и [проверке изменений](docs/verification.md). Команды проверок этой базы перечислены в package.json; команды приложения берутся из выбранного target. Публикация и CI/CD требуют явного поручения по [локальной политике](docs/local-workflow.md).
