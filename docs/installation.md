# Установка и режим работы

Вход агента — [AGENTS.md](../AGENTS.md). Node берётся из `package.json`, зависимости устанавливаются по lockfile. Lefthook обслуживает этот checkout, не репозитории продуктов.

## Разработка общей базы

Работай в ветке `dev`. Переменная `E2E_MANIFEST_DEV=1` обязательна для установки, commit и push:

```sh
export E2E_MANIFEST_DEV=1
npm ci
```

Разработка сохраняет все стековые модули. Если checkout был сокращён, установка возвращает их через отключение sparse checkout. Уже существующие локальные данные не удаляются. Переменная задаётся в текущем shell/запуске агента; глобальные настройки не меняются.

## Использование в продуктовом проекте

Клонируй базу отдельно от приложений и используй ветку `main`. Выбери объединение модулей, необходимых всем целям MyProject:

```sh
E2E_MANIFEST_DEV=0 E2E_MANIFEST_STACKS=playwright,msw npm ci
```

Без явного списка или при неизвестном ID установка завершается ошибкой до сокращения. Проверяются незакоммиченные изменения и неотслеживаемые файлы в stack. Конфликт не исправляется удалением или stash.

Невыбранные каталоги `stack/<id>/` физически исключаются из рабочего дерева через Git sparse checkout; история и index сохраняются. Это не удаление исходников из Git. Общие docs, schemas, skills, инструменты и `workdir/` остаются. Нельзя удалять весь невыбранный контент произвольным `rm -rf`.

Для изменения выбора повтори `npm run setup` с нужными переменными. Выбор всегда явный; предыдущий список не применяется по предположению. Обновление `main` выполняется отдельно, затем setup запускается вновь. Setup не делает fetch, switch, commit или push. В detached HEAD или другой ветке он отказывает.

`workdir/installation.json` — производная запись режима, ревизии установки и набора модулей, не проектный нормативный manifest. Остальное содержимое workdir не перезаписывается. Параллельное обновление общей поставки во время её использования не поддерживается.

## Hooks

| Hook / task | Действие |
| --- | --- |
| npm `postinstall` | Установить Lefthook hooks и вызвать задачу `setup` |
| Lefthook `setup` | Проверить mode/branch и выбрать стек |
| `pre-commit` | Проверить dev-режим, локальные ссылки, JSON syntax и staged whitespace |
| `pre-push` | Проверить dev-режим, ссылки и тесты механизма установки |

Hooks не заменяют серверную защиту веток. На consumer main commit/push блокируются установленными hooks; публикация всё равно требует поручения. Hooks `post-checkout` и `post-merge` не сокращают файлы автоматически.

Если используется `npm ci --ignore-scripts`, установка неполная: вручную выполни `npm exec lefthook install`, затем `npm run setup`. При существующем `core.hooksPath` не обходи конфликт через force/reset; сначала согласуй интеграцию с владельцем hooks.

Текущий stack-каталог — первый этап разделения существующей Playwright/MSW документации. Он не объявляет готовую поддержку TesterArmy или произвольного стека.
