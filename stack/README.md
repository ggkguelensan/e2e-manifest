# Стековые модули

Выбор задаётся при установке через `E2E_MANIFEST_STACKS` (ID через запятую). В main остаются выбранные модули; dev содержит весь набор. Каталог модулей — `stack/catalog.json`.

- `playwright`: UI-абстракции и права слоёв.
- `msw`: HTTP runtime и его lifecycle.

Это первый этап выделения стека: общие docs и skills пока описывают преимущественно Playwright + MSW. Выбор одного модуля не означает полную поддержку другого runner/backend. TesterArmy пока не реализован.

Правила отсутствующего модуля не применяются по догадке. Если задача требует его, расширь выбранный набор через повторную установку. [Протокол установки](../docs/installation.md).
